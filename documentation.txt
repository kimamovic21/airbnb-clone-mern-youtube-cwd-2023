Airbnb Clone Fullstack MERN App


Vite React project setup

-open link: https://vite.dev/guide/
-create folder client and type command: npm create vite@latest .
-type command: npm run dev
-open link: https://tailwindcss.com/docs/installation/using-vite
-type command: npm install tailwindcss @tailwindcss/vite
-in vite.config.js import function tailwindcss from package @tailwindcss/vite
-in index.css add directive @import "tailwindcss"
-add favicon icon


Header component

-open link: https://react-icons.github.io/react-icons
-type command: npm i react-icons
-create folder components and component Header.jsx
-in component Header.jsx import react icons from package react-icons
-in jsx create HTML elements with Tailwind CSS classes
-in component App.jsx import component Header from components/Header.jsx
